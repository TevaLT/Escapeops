Lecture : l'application écrit des DATETIME en heure de Paris (UTC+1 en novembre).
Un UPDATE ... = NOW() + INTERVAL 10 MINUTE lancé SANS SET time_zone écrirait une heure UTC,
que l'application lirait comme heure de Paris : l'option paraîtrait expirée depuis ~50 min.
Toutes les requêtes de vieillissement de ces preuves commencent donc par SET time_zone='Europe/Paris'.
